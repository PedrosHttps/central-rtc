    DANFSe

    Transforme XMLs de NFS-e autorizadas em PDF: uma nota ou uma pasta inteira de uma vez.

      Em lote

      Calcule muitos itens a partir de uma planilha CSV. Cada linha é um item; a coluna operacao junta os itens da mesma nota.

      Para automatizar sem abrir o navegador (no agendador do sistema, por exemplo), use a linha de comando: node cli.js lote simples planilha.csv. Os detalhes estão no README.

      As calculadoras e o gerador de DANFSe são projetos de código aberto da Receita Federal. A Central RTC só organiza as chamadas; confira os resultados antes de usá-los em documentos fiscais.
